Pill call-to-action button; one primary per view ("Inizia il questionario", "Prenota").

```jsx
<Button>Inizia il questionario</Button>
<Button variant="secondary" size="s">Scopri di più</Button>
<Button variant="inverse" iconRight="→">Trova il tuo terapeuta</Button>
```

- `primary` violet fill; `secondary` lavender; `outline`; `inverse` white on violet grounds; `ghost` for tertiary.
- Hover darkens one step; press scales to 0.97.
